# การสุ่มทำใน Postgres function ไม่ใช่ในเบราว์เซอร์หรือ Edge Function

การสุ่มผู้โชคดีทำใน Postgres function ที่ถูกเรียกผ่าน RPC โดยตรวจสิทธิ์แอดมิน เลือกการลงทะเบียนแบบสุ่มจากกลุ่มผู้มีสิทธิ์ แล้วบันทึกผู้โชคดีใน transaction เดียว ใช้การล็อกแถวเพื่อให้แอดมินสองเครื่องที่กดพร้อมกันไม่ได้คนเดียวกัน เบราว์เซอร์แค่เรียก function แล้วเล่น animation ตามผลที่ได้ (รายชื่อที่หมุนบนจอเป็นแค่ effect)

## Considered Options

- **สุ่มในเบราว์เซอร์ของแอดมินแล้วเขียนผลลง DB**: ไม่ใช้ เพราะแอดมินแก้โค้ดให้ได้ผลตามต้องการได้ และกันสองเครื่องกดพร้อมกันไม่ได้
- **Supabase Edge Function**: ไม่ใช้ เพราะเพิ่ม runtime ที่ต้อง deploy/ดูแลอีกตัว แต่ยังต้องพึ่ง transaction ใน DB อยู่ดี
